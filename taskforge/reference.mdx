## Tiers

Hum grants each person one tier. Tiers add up: `l2` reaches everything `l1` does.

| Tier | Who | Adds |
| --- | --- | --- |
| `kennet:l1` | Task authors | Check and run bundles, read runs, adjudicate, follow your tasks. Runs only the models the gateway's `l1` list holds |
| `kennet:l2` | Trusted authors | Any catalog model, the authoring tools, `review_run`. `run_repo_to_tasks` at most $100 a session |
| `kennet:l3` | The Metaphi team | Calibration, consults, parked passes, traces. `run_repo_to_tasks` at most $500 a session |
| `kennet:anonymize` | A capability, not a tier | `upload_trace`, `anonymize_trace`, `pull_trace` and your own jobs |

A tool above your tier is not listed. Beyond the tier, GitHub decides at the call: a tool that launches or writes needs push to the repository, a read needs read.

## Common refusals

A refusal comes back as a tool error with one sentence that names what to fix.

| Refusal | Do |
| --- | --- |
| `<tool> needs kennet:l2 and you hold kennet:l1; ask Metaphi for kennet:l2` | Ask for the tier, or use a tool your tier lists |
| `<tool> on kennet:l1 runs <models>; ask Metaphi for kennet:l2` | Pick a model from the list it names |
| `run_repo_to_tasks on kennet:l2 spends at most $100 (cost_budget_usd)` | Lower `cost_budget_usd` |
| `sign in to Hum with GitHub to work on a repository` | Sign in again with GitHub: `hum mcp login kennet` |
| `you do not push to <repo> on GitHub, and this call writes to it; ask its owner for write access` | Get write access, or work in a repository you push to |
| `you do not read <repo> on GitHub` | Check the name and your access |
| `<repo> has no ref <ref>` | Push the branch first; Kennet clones GitHub, never your checkout |
| `name a bundle in <repo> by ref + path, or by staged for one already on its runs` | Pass `ref` and `path` (or `paths`), not both forms |
| `mode conduct requires at least one model` | Pass `models` |
| `reasoning_effort is required: name the effort this run is to use (for example medium) …` | Pass `reasoning_effort` |
| `no run started: the gateway preflight did not answer …` or `every model was refused …` | Nothing ran and nothing was spent. Try again later, or pick another model |
| `task <id> asks no open question <qid>` | The question was answered or withdrawn; `get_task` shows what is open |
