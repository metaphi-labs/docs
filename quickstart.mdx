## 1. Install

macOS (Apple silicon) and Linux:

```bash
curl -fsSL https://humboldt.metaphi.ai/install.sh | sh
```

Windows (PowerShell):

```powershell
irm https://humboldt.metaphi.ai/install.ps1 | iex
```

npm or uv (any platform, including managed Windows machines):

```bash
npm install -g @metaphi-ai/hum
uv tool install hum-cli
```

Check it:

```bash
hum --version
```

## 2. Sign in

```bash
hum login
```

The browser opens. Sign in with Google or GitHub and confirm the code shown in the terminal. Once per machine.

## 3. Run a task

```bash
cd your-repo
hum "make the nightly job idempotent"
```

While it works:

| Do | Effect |
| --- | --- |
| Type | Steer it |
| `esc` | Stop the turn, keep the work |
| `ctrl+c` twice | Leave. The session keeps running |
| `hum resume` | Come back |

## Update

```bash
hum update
```

When a newer release is out, Hum asks at start: update now (it installs and starts again on the new version), not now (it installs in the background and takes effect next time), or skip this version. `HUM_NO_AUTO_UPDATE=1` keeps the question and stops the background install; `HUM_NO_UPDATE_CHECK=1` turns it all off.
